# ⚡ HACK Z 2026 — VIMTECH Intra-College Hackathon (BCA Department)

A lightning-fast, modern, zero-overhead web application engineered for maximum performance, bulletproof CSS styling, and seamless user experience.

---

## 🚀 Instant Launch

### Option 1: Open Directly (Zero Dependencies, 0s Loading)
Simply double-click `index.html` or open it in any modern browser! Everything (CSS styling, interactive canvas, registration modal, admin portal, Supabase integration) is self-contained.

### Option 2: Run Local Dev Server
```bash
npm run dev
# or
npx serve -l 3000 .
```
Access the application at `http://localhost:3000`.

---

## 💎 Features & Highlights
- ⚡ **Ultra-Fast Performance**: Zero complex bundler or hydration overhead. Boots instantly.
- 🎨 **Bulletproof CSS & Design System**: Responsive electric cyberpunk theme (Electric Cyan `#00F0FF`, Hyper Violet `#8B5CF6`, Neon Emerald `#10B981`) that never breaks.
- 🌌 **Interactive Cyber Canvas**: Real-time particle connection visualizer on the hero banner.
- 📝 **Multi-Step Squad Registration**: Team leader + up to 4 squad members with automatic pass generation.
- 📊 **Built-in Admin Suite**: Real-time registration filtering, search, inspector, and CSV export.
- ☁️ **Supabase Cloud Sync**: Direct lightweight Supabase JS client integration for real-time cloud data storage.
